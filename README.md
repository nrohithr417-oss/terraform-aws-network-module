# Terraform AWS Network Module

## Overview

This repository contains a reusable Terraform module for provisioning production-ready AWS networking infrastructure.

## Features

- VPC
- Internet Gateway
- Public Subnets
- Private Subnets
- NAT Gateway
- Route Tables
- Network ACLs
- Security Groups
- VPC Flow Logs
- VPC Endpoints
- IPv6 Support
- Multi-Environment Support

## Environments

- Development
- QA
- Stage
- Production
